Правила перевода без ИИ

Вернуться к переводчику

Простые предложения переводчик собирает сам, без ИИ: слова берёт из словаря (словарик проекта и PaydaDosh), грамматику — из справочника, проверенного по ингушским текстам и словарям. Каждое правило написано по образцам из источников. Если для предложения правила нет или нужной формы нет в источниках, правило молчит, и переводит ИИ.

Под каждым образцом показано, как его собирают правила. Перевод по правилам совпадает с переводом носителей в разговорнике PaydaDosh примерно в 3 случаях из 4: правила пока простые, поэтому важное проверьте у носителя языка.

Библиотека слов — файл lib/rules/lexicon.js, библиотека правил — lib/rules/grammar.js. В них можно добавлять новые слова и правила.
