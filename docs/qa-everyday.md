# Проверка на простых бытовых предложениях (без ИИ)

Носитель языка сказал: переводчик ошибается на простых фразах вроде «отвези еду». Здесь — что показала
проверка на 466 бытовых предложениях и откуда берутся ошибки. Код не менялся; только замер.

```sh
node scripts/check-everyday.js          # все: вход → выход [откуда] флаги
node scripts/check-everyday.js --bad    # только с флагами
```

Скрипт вызывает сервер (`api/translate.js`) так же, как `test/chunks.test.js`, раздел 7: без сети, пустое
хранилище, `USE_AI` не задан. Русские предложения (337) — бытовые фразы. Ингушские (129) — только из примеров
справочника (`lib/ingush-guide.js`) и фраз PaydaDosh (`data/phrases.json`), часть — с минимальной заменой
(местоимение, слово того же класса) словами из этих же фраз. Код: ветка `claude/project-thread-kwscnp` на
коммите `7e4ffb0` (с падежами, ru-conj, таблицей фраз).

Автоматические флаги ловят только видимые поломки ([скобки], русские слова, пояснения, повторы, связку при
глаголе). Большинство ошибок — **неверный смысл или форма**, флагами не ловятся; они разобраны вручную ниже.
По оценке при чтении всех 187 ответов «по словам» ru→inh: примерно треть приемлемы, треть понятны, но с
неправильной формой (время, класс, падеж), треть — неверны по смыслу.

Где ответ из базы (120 из 337 ru→inh, 86 из 129 inh→ru) — почти всё правильно: проблемы только с
пояснениями в ответе (раздел 9). Ингушский → русский в целом хорош; слабое место — замена слова по аналогии
без согласования (раздел 10).

## Ошибки по причинам

Строки кода — `lib/rules/chunks.js` на `7e4ffb0`, если не сказано иначе.

### 1. Таблица слов (ALIGN) перебивает словарь проекта — неверное значение

`ruWord()` (строки ~222–224 «`const al = aligned(w, "ru", false); if (al && al !== low(d.to)) { … d.to = al }`»):
если таблица, выученная из пар фраз, знает слово, она заменяет перевод из **словаря проекта (prio 0)**.
Таблица выдаёт то ингушское слово, которое чаще стоит рядом, — часто падежную форму или соседнее слово.

| вход | выход | что не так |
|---|---|---|
| Как зовут твою сестру? | Санна хьа йиша дех? | «как» → «санна» (сравнение «как кто-то»); в словаре проекта «мишта / санна» |
| Сколько у тебя детей? | Фу хьога бераш? | «сколько» → «фу» (что); в словаре проекта «масса / мел» |
| Она варит обед | Цо делкъийга кхехкаде | «обед» → «делкъийга» (форма «к обеду») |
| Мама готовит обед на кухне | Нана делкъийга кухни кийчде | то же |
| Когда ты придёшь? | Маца ва хьо хьо? | «придёшь» → «хьо» (соседнее слово из пары «… хьо?») |
| Положи еду на стол | Даар шу дилла | «стол» → «шу» (таблица), в разговорнике «истол» |
| Он пришёл домой | Из венав цӀа ва | «пришёл» → «венав» в обход `OPEN_PAST` (см. 6) |

**Исправить:** в `ruWord()` не подменять перевод из словаря проекта (`d.src` = словарь проекта, prio 0)
таблицей; для prio ≥ 1 подменять, только если `ALIGN.best` ≥ 0.5 и слово-перевод не служебное (местоимение,
связка, вопросительное слово — их нет среди переводов существительных). Добавить в `QUESTION_WORDS`
(`lib/rules/lexicon.js`, строка 200) `"сколько": "мел"` (PaydaDosh: «Мел ха яьннай хьа?», «Мелла ба уж?»),
а «как» в `ruWord` (строка 150) не исключать, когда это вопрос «как + глагол» — «мишта» (справочник: «Мишта
дах шо?»).

### 2. Перевод по аналогии (`analog()`) заменяет не то слово

`analog()` (строка ~729): в готовой фразе ищется слово с наибольшей `ALIGN.prob(o, t)` и порогом 0.2. Порог
низкий, и таблица часто связывает русский глагол с местоимением или заимствованием.

| вход | образец из разговорника | выход |
|---|---|---|
| Куда ты едешь? | Куда ты идёшь? — Мича вода хьо? | Мича вода **вода**? (заменено «хьо») |
| Включи свет | Выключи свет — Свет дӀайоае | **Сега** дӀайоае (заменено «свет», глагол «выключи» остался) |
| Дай руку | Дай Бог — Дала аьннадале | Карара аьннадале (идиома «дай Бог» как образец) |
| Два брата | (словарь) | Веший ши кӀаьнк («двоюродные братья») |
| Четыре книги | ? | Кинижка ди (число пропало) |
| Я сделал работу | Я закончил работу — Болх баь яннай со | Болх дир яннай со |
| Помой руки | ? | БӀеха хиш дӀамехкаду кулгаш |

**Исправить:** (а) порог `tune.ap` поднять (0.2 → 0.5) и требовать, чтобы заменяемое слово было лучшим
переводом `o` **в обе стороны** (`ALIGN.best(t,"inh").to === o`); (б) не брать образцы, где заменяемое слово —
часть устойчивого выражения (`дай Бог`, `спасибо большое`), т. е. если в образце ≤ 2 слов; (в) после замены
проверять, что в ответе не появилось двух одинаковых слов (флаг `dup`) — тогда отказаться от аналогии.

### 3. Повелительное наклонение: [скобки] и чужие формы

`imperative()` (строки 128–145) понимает только формы, у которых в словаре есть начальная форма с prio ≤ 1.

- в [скобках]: «Убери посуду → [убери] пхьегӀаш», «Позови отца → [позови] даь», «Позови врача → [позови] лор»,
  «Приходи завтра → [приходи] кхоана» (последнее — намеренно, OPEN_PAST), «Они пришли вчера → Уж [пришли] селхан ба».
  `RET.lemmas("позови")` пусто, хотя «позвать — деха / хьадеха» в PaydaDosh есть. Нужна ветка в `lib/morph.js`
  (повелительное -и/-ите → -ать/-ить/-ять с проверкой по словарю): «позови → позвать», «убери → убрать».
- неверная начальная форма: «Уходи → бахар» (раньше: принято за сущ. «уход»; на 7e4ffb0 исправлено:
  «дӀааха»). «Не плачь → Ма белхар» — «белхар» это прошедшее/отглаг. существительное, а не повелительное.
- прошедшее вместо повелительного: «Ложись спать → Наб е дижар».
- первый смысл слова из PaydaDosh («ба / да / хьада» для «принести»): «Принеси воду → Хий ба», «Принеси чай →
  Чай ба», «Принеси хлеб → Маькх ба». В PaydaDosh формы с классом идут через «/» отдельными записями — `classForms`
  их не собирает, берётся первая запись (класс б), а «хий» — класс д. **Исправить:** в `imperative()` при
  нескольких записях prio 1, отличающихся только начальной буквой класса (ба/да/ва/я), собирать их в `byClass`
  и выбирать по классу дополнения (как `byObject` для «люблю»). Тогда «Хий да», «Маькх» — по классу из словаря.

### 4. Нет нужного глагола — модуль ставит связку (ва/я/да/ба) после чужого слова

`sentence()`, строка ~610: связка ставится, если `!out.some(x => x.verb)`. Если глагол не распознан (в скобках,
переведён существительным или словом из таблицы), предложение считается безглагольным.

| вход | выход |
|---|---|
| Он пришёл домой | Из венав цӀа **ва** |
| Почему он не пришёл? | ХӀана из венав **вац**? |
| Когда ты пришёл? | Маца **ва** хьо венав? |
| Мы работаем вместе | Тхо болх цхьана **да** |
| Магазин закрыт | Тика къовла **я** |
| Они пришли вчера | Уж [пришли] селхан **ба** |
| У него три сына | Из кхо воӀ **ва** |
| Мой отец работает | Са да **ва** болх бе (связка внутри куска из таблицы фраз) |

**Исправить:** не ставить связку, если в предложении есть кусок `how: "unknown"` или русское слово с
глагольным окончанием (`VERBISH`) и начальной формой-глаголом (`RET.lemmas(w).some(isVerbLemma)`), даже если
перевод для него не глагол. Куски `align-phrase`, которые кончаются на связку, а за ними идёт глагол, не
брать (строка 555).

### 5. Время и лицо глагола: берётся словарная форма

Если в строке словаря нет «наст./прош.», ставится инфинитив (строка ~219, «нужной формы нет — словарная
форма»). Будущего времени нет совсем.

- прошедшее → инфинитив: «Он купил машину → Цо машен эца» (PaydaDosh: «Дас машен ийцай»), «Я купил хлеб →
  Аз маькх эца», «Мы купили дом → Оаха цӀа эца», «Дети спали → Бераш наб е», «Он прочитал книгу → Цо книжка
  беша» (PaydaDosh: «КӀаьнко кинишка дийшад»), «Я забыл → Аз дицде».
- будущее → инфинитив/настоящее: «Завтра будет дождь → Кхоана догӀа хила», «Я позвоню тебе завтра → Аз хьона
  кхоана гургал тоха», «Я сделаю это → Аз ду из» (PaydaDosh: «Аз эцаргда из» — образец -аргда), «Она будет
  работать → Из болх бе хила».
- неверный глагол из первой записи: «Девочка читает книгу → ЙиӀиг книжка деш», «Я читаю книгу → Аз книжка деш»
  («деш» — наст. от «деша», но и «делая»); «Мой дедушка болеет → Са даьда лаза» («лаза» — болит);
  «Светит солнце → Малх сердал тела».
- «пошёл / пойду / приедет → ба / ва»: «Куда он пошёл? → Мича из ба?», «Мы пошли домой → Оаха цӀа ба»,
  «Она пошла в магазин за хлебом → Из тика маькх ба», «Он приедет завтра → Цо кхоана ва», «Завтра я пойду на
  работу → Кхоана аз балха ба». В PaydaDosh у «пойти» и «приехать» первая запись — одна буква класса («ба»,
  «ва»), `dictWord()` (строка 78–94) берёт её как перевод. **Исправить:** в `dictWord()` пропускать записи из
  одной-двух букв, совпадающие со связкой (`L.COPULA`), как это уже сделано для «прош./наст./мн.».
- эргатив при непереходном глаголе: «Он приедет завтра → **Цо** кхоана ва», «Завтра я пойду на работу → **Аз**
  …» — `tv` (строка ~631) ставит эргатив, потому что «ба/ва» не помечены возвратными, а «завтра», «работу»
  приняты за прямое дополнение. **Исправить:** считать дополнением только существительное в винительном
  (у `RUC`/`cases.js` есть падеж), не наречия времени.

Будущее и прошедшее для частых глаголов можно брать только из засвидетельствованных пар: PaydaDosh даёт
«эцаргда» (куплю), «яьздергда» (напишу), «воагӀаргва» (приеду), «ийцай» (купил), «дийшад» (прочитал),
«деттад» (построил), «аьлар» (сказал). Их можно добавить в `L.VERBS` (`lib/rules/lexicon.js`) со ссылкой на
фразу; остальное — оставить инфинитивом, как сейчас.

### 6. «пришёл / пришла» проходят в обход открытого вопроса

CLAUDE.md: формы «пришёл» (вера / хьавенав) ждут подтверждения. `OPEN_PAST` проверяется только в ветке
словаря (строки 208, 275), а таблица слов и аналогия его не знают:
«Он пришёл домой → Из **венав** цӀа ва», «Когда ты пришёл? → Маца ва хьо **венав**?», «Кто пришёл? → Мала
**хьавенав**?», «Она пришла → Из **хьаенай**», «Он не пришёл → Из **венавац**».
Формы засвидетельствованы в PaydaDosh («Мальчик пришёл — КӀаьнк хьавенав», «Никто не пришёл — Саг венавац»),
но по правилу проекта их не выдаём, пока семья не подтвердит. **Исправить:** в `aligned()` (строка 51) и
`analog()` отказываться, если русское слово — форма из `OPEN_PAST` (через `RET.lemmas`).

### 7. Прилагательное: класс не согласуется, сказуемое теряется

- класс прилагательного не по существительному: «Большой дом → **Воккха** цӀа» (цӀа — класс д; в разговорнике
  «Дом большой → ЦӀа доккха», «Большие дома — Доккхий цӀенош»); «У нас большая семья → Тхога **йоккха** дезал ба»
  (дезал — б). Форма берётся из пары «большой мальчик / большая девочка». **Исправить:** у прилагательных с
  классным показателем (в-/й-/д-/б- в начале, `L.ADJECTIVES`) менять первую букву по классу существительного,
  только если такая форма есть в словаре/словоформах (`lib/ingush-words.js`: доккха, йоккха, воккха, боккха).
- сказуемое стало определением: «Мальчик маленький → ЗӀамига кӀаьнк», «Хлеб свежий → Моша маькх», «Еда
  вкусная → Чам болаш хӀама» (аналогия по образцу словосочетания).
- нет связки, потому что класс существительного неизвестен: «Мясо готово → Дулх кийча», «Ужин готов? → Пхьор
  кийча?», «Погода хорошая → Хаоттам дика», «Чай горячий → Чай дӀайха», «Дом большой → ЦӀа доккха»,
  «Вчера было холодно → Селхан шийла». Строка ~610: `cls` берётся только из `PERSON_CLASS`/`ATTESTED_CLASS`
  или словаря для начальной формы; «дулх», «пхьор», «хаоттам» в словаре PaydaDosh записаны с классом
  (`(д)`), но `dictCls` ищет шаблон «(в/…» и пропускает «(д)» без косой черты. **Исправить:** в `dictWord()`
  (строка ~95, `cm = /\(\s*([вйдб])\s*[\/,-]/`) принимать и «(д)», «; д, д»: `/[(;]\s*([вйдб])\s*[\/,);]/`.

### 8. «у него / у неё есть», «есть» как «кушать»

`sentence()` строка 524: «у + местоимение» → направительный падеж `PRONOUNS[p].all`; у «он/она/они» там `null`,
поэтому «у» пропускается, а «него» становится «из».
- «У него три сына → Из кхо воӀ ва», «У него есть сестра → Из йиш я ва», «У неё есть дети → **Цо** бераш **даа**»
  («есть» = «кушать», «даа»).
**Исправить:** `all: "цунга"` для «он» и «она» в `lib/rules/lexicon.js` (строки 21–22) — засвидетельствовано
PaydaDosh: «У него нет времени — Ха яц цунга». Для «они» формы в источниках не нашлось — оставить `null`.
И в строке 529 обрабатывать «есть» после «у кого» и тогда, когда «у …» не распознано (не отдавать «есть» в
`VERB_FORMS` как «кушать», если в предложении был предлог «у»).

### 9. Пояснения словаря и варианты попадают в ответ (ответы из базы)

`seedResult()` / `fromDictionary()` (`api/translate.js`, строки ~949–953) отдают строку словаря целиком.
- «Здравствуйте → Ассалам Ӏалайкум (ответ: Ва Ӏалайкум салам); Ӏуйре / Ди / Сайре дика хийла хьа (шун) — по
  времени суток» (из словаря проекта, а в справочнике есть готовая фраза «Ассалам Ӏалайкум!»)
- «Я хочу есть → Яа хӀама (еза) езар сона.»
- «Подожди немного → КӀеззига сабарде (сабарделахь).»
- «Извини → Бехк ма баккхалахь / Бехк ма баккхалаш» (два варианта через «/»)
**Исправить:** в ответе оставлять текст до первой «(» или « / », а скобки и варианты — в `details.note`/
`variants`; для записей словаря проекта с «(ответ: …)» сначала искать фразу справочника (`KB.EXAMPLES`).

### 10. Ингушский → русский: аналогия не меняет лицо глагола и род

`analog()` для `lang = "inh"` меняет одно слово, но русский глагол остаётся в лице образца:
- «Хьо гӀоргвац? → Ты не **пойду**?», «Хьо дешаш ва? → Ты **учусь**?», «Хьо кхоана воагӀаргва? → Ты **приеду**
  завтра?»
- род по связке: «Из студент я → **Он** студент» (я — класс й, должно быть «она»; ср. тест: «Из кхалсаг я → Она
  женщина», а на этом коммите «Из кхалсаг я. → **Это** женщина» по правилам грамматики).
- имя с маленькой буквы: «Из Наьсарера ва → Он из **назрани**».
- повелительное → инфинитив: «НиӀ дӀакъовла → Дверь **закрыть**» (образец «Кор дӀакъовла — Закрой окно»
  заменил и глагол: «закрыть» пришло из словаря).
- неверный смысл: «Сона нана еза → Мне **нужна** мать» (справочник: «Сона хьо еза — Я тебя люблю»).
**Исправить:** после замены в `analog()` (inh) пропускать результат через `ru-conj` (у сервера есть `RUC`):
если заменено местоимение, переспрягать русский глагол образца по новому лицу, а если не получается —
отказаться от аналогии и перевести `sentence()`. Имена из исходника (с заглавной) сохранять в регистре
исходного текста.

### 11. Прочее

- падеж/число существительного теряется: «Отвези детей в школу → **Бер** ишколе дӀадига» (детей → бер, ед. ч.;
  надо «бераш», как в «Дети спят → … бераш»); «Скажи матери → **Гила** ала» («матери» → неверная запись
  словаря при поиске по форме; в словаре проекта мать — «нана»; нужен дательный «наьнага», PaydaDosh: «Аз
  наьнага дӀааргда из»).
- «семью» → «семь»: «Я люблю свою семью» (до 7e4ffb0: «ийгӀача»; теперь «дезал беза» — хорошо).
- «его» перед наречием — как «чей»: «Я видел его вчера → Сона **цун** селхан гайра». Строка 154: «его» → род.
  падеж, если следующее слово не глагол/местоимение; «вчера» — наречие. **Исправить:** проверять, что
  следующее слово — существительное (`dictWord(next).noun`) или прилагательное.
- отрицание не в том месте: «Мне не нравится → Сона хоза хет **ца**» (аналогия; PaydaDosh: «Сона хоза хетац из»).
- «Ничего нет → ХӀама а» (PaydaDosh «Сога хӀама дац»: «нет» здесь «дац», а не «а» — «нет» как ответ).
- идиомы по словам: «С днём рождения → Дийнахьа бер хьахилар», «Рад тебя видеть → Воккха ве Ӏа гу».
  Таких фраз в источниках нет — честнее не отвечать (вернуть `null`), чем собирать по словам.
- «Где школа? → **Школа** мичахьа я?», «Наша школа → Тха школа»: первый вариант словаря проекта «школа / ишкол»
  — русское слово; в разговорнике «ишкол(е)». Поменять порядок вариантов в источнике (`lib/ingush-guide.js`
  GLOSSARY), не в `phrases.json`.
- «чай»: ответы «Чай ба», «Пей чай → Чай мала», а в PaydaDosh «Чей дотта сона». Постпроверка не ловит, потому что
  «чай» есть в ингушской части какой-то записи.

## Сравнение с разговорником

117 русских и 40 ингушских предложений почти совпадают с фразой разговорника (одно слово другое) — скрипт
показывает обе для сравнения (`pb-near`). Полных совпадений с другим ответом (`pb-mismatch`) — 2, оба
не ошибки по сути: «Как дела?» → «Фу деш ва хьо?» (из справочника, а в PaydaDosh есть ещё «Миштад хьа
гӀулакхаш?»), «Здравствуйте» — см. раздел 9.

Полезные пары «почти то же»:
- «Ты поел? → Хьо йиай?» — PaydaDosh «Я уже поел — ХӀама йиай аз» (эргатив: «Ӏа»).
- «Я работаю → Аз болх бе» — PaydaDosh «Мичахьа болх беш ва хьо?» (настоящее — «беш ва»).
- «Я понимаю → Со кхета» — PaydaDosh «КӀезига кхета со».
- «Он купил машину → Цо машен эца» — PaydaDosh «Дас машен ийцай».
- «Говори медленнее → Шортига дувца» — PaydaDosh «ШортагӀа дувца».

## Ограничения проверки

- Флаг `verb-lost` эвристический: «еду», «дети», «матери» — и глаголы, и существительные; такие слова
  исключены, если в словаре есть начальная форма-существительное. Возможны пропуски.
- Флаг `russian` (lib/postcheck.js) не ловит заимствования, которые где-то записаны как ингушские («школа»,
  «чай», «книжка», «кухни»).
- Оценка «правильно/неправильно» вне флагов сделана по разговорнику и справочнику, не носителем.
