# Админка `/admin`

Страница для владельца сайта: что люди переводили и жалобы с кнопки «Неправильный перевод?».

- **Жалобы** — новые сверху, кнопка «Обработано ✓» (и «Вернуть в новые»), фильтры по направлению, периоду и статусу, поиск, CSV.
- **Что переводили** — журнал последних 3000 переводов: текст, перевод, направление, время и откуда ответ (база, правила, по словам, ИИ, не нашлось).
- **Обзор** — цифры, графики по дням и неделям, жалобы по дням, направление, откуда ответ (база, правила, по словам, не нашлось),
  **частые запросы** и **слова без перевода** (что ищут, а словарь не знает) — у каждого кнопка «Исправить» / «Добавить».
- **Исправить перевод** прямо из жалобы, журнала или частых запросов: перевод сохраняется в словарь сайта (тот же список,
  что у кнопки «Исправить» на главной), и сайт сразу отвечает им как носитель языка. Жалоба отмечается обработанной.
- **Словарь** — все исправления сайта: поиск, добавить, изменить, удалить (удаление — двойным нажатием).
  База `data/phrases.json` отсюда не меняется: её правят только через источники и `scripts/build-phrases.js`.
- **Копия** — одна кнопка скачивает JSON со словарём сайта, решениями `/review`, жалобами и журналом.
- **Очистка** — журнал переводов, обработанные или все жалобы, графики. Перед очисткой сама скачивается копия,
  а последнюю очистку можно вернуть кнопкой «Вернуть» (хранится в ключе `trash`). Словарь очисткой не трогается.

Журнал хранит только текст и перевод: без IP-адресов, браузера и других данных о людях.
Хранится там же, где исправления: Supabase (таблица `kv`, ключи `log`, `log-stats`, `reports`), Netlify Blobs
или `local-data/` при запуске `node server.js`.

## Включить

1. Придумайте код (длинный, не как `EDITOR_CODE`).
2. Railway → проект `ingush-translator` → сервис `web` → **Variables** → `ADMIN_CODE` = ваш код. Railway сам перезапустит сайт.
   Локально — строка `ADMIN_CODE=...` в `.env`.
3. Откройте `https://<сайт>/admin` и введите код. Код помнится до закрытия вкладки.

Без `ADMIN_CODE` админка выключена. `ADMIN_LOG=0` — не вести журнал переводов (жалобы всё равно сохраняются).
