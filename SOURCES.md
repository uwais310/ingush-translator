# Источники базы пар (data/phrases.json)

В базе только пары, взятые из настоящих источников. Ни одно ингушское слово не придумано и не
сгенерировано ИИ. У каждой записи есть поле `source` (откуда она), у записей из открытых словарей —
ещё `license`, а `verified` у всех `false`: «проверено» ставит только носитель языка на странице `/review`.
Если одна и та же пара есть в нескольких источниках, остальные перечислены в поле `also`.

Как собрать заново:

```
python3 scripts/fetch-open-sources.py      # скачивает источники в .cache-sources/ и пишет data/sources/*.json
node scripts/fetch-paydadosh.js            # PaydaDosh (с разрешения владельцев): ≤ 1 запроса в секунду, ~25 минут → data/sources/paydadosh.json
node scripts/build-phrases.js              # чистит, проверяет и собирает data/phrases.json
```

Чистка при сборке (`scripts/build-phrases.js`): палочка `1 / I / l / | / і` → `Ӏ`; дубли убираются;
каждое ингушское слово записи (кроме имён собственных) должно встречаться в корпусе ингушских текстов
(`lib/ingush-words.js`, частотный словарь YandievRuslan/ing_freq_dict); записи с известными чеченскими
формами (`lib/base.js`, CHECHEN) не берутся ни из какого источника.

\* «Вошло в базу» меньше «скачано»: убраны дубли (в том числе с записями из источников выше в таблице),
пары со словами, которых нет в ингушских текстах, и с чеченскими формами. Точные числа печатает
`node scripts/build-phrases.js`.

**PaydaDosh.** Записи PaydaDosh взяты с разрешения владельцев сайта (по словам владельца проекта). Это не открытая
лицензия: базу с этими записями нельзя выкладывать или передавать другим без согласия PaydaDosh. Сайт скачивался
вежливо: не больше 1 запроса в секунду, только разделы, открытые для поисковиков (robots.txt), без /api/.

**Пометки и разделы.** Пометки, которые стояли в скобках внутри ингушского текста («(говорит мужчина)», «(к женщине)»,
классы «(й, б, д)»), сборка переносит в поле `note` — сайт показывает их подписью варианта, и при копировании они
не попадают в перевод. Ингушские слова не меняются; варианты слов в скобках («(шун)», «(еза)») остаются в тексте.
Раздел PaydaDosh, откуда взята фраза («разговорник: уроки (УРОКИ)»), хранится в поле `section`. id записей не меняются.

**Порядок надёжности** (какой источник показывается первым и получает галочку на сайте): проверено носителем >
словарь проекта > PaydaDosh > Викисловарь > Википедия / Викиданные > PanLex > корпус (статистика слов) > translatewiki.

**Атрибуция.** Записи из Викисловаря и Википедии — CC BY-SA 4.0, из translatewiki.net — CC BY 3.0:
при повторном распространении базы нужно указывать эти источники (этот файл) и распространять
изменённые записи CC BY-SA на тех же условиях. PanLex и Викиданные — CC0, условий нет.
