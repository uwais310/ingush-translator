# Передача проекта (HANDOFF)

Ингушский переводчик без ИИ. Для следующего Claude / человека, который продолжит работу.
Обновлено: 20 ноября 2026.

## Что сейчас

- Сайт переводит **без ИИ** по умолчанию. ИИ включается только переменной окружения `USE_AI=1`.
- Порядок перевода (см. `CLAUDE.md` и `docs/translation-rules.md`): исправления носителей → база фраз и словари →
  правила грамматики (`lib/rules/grammar.js`, `reverse.js`) → шаблоны «…» и аналогии → перевод «по кускам»
  (`lib/rules/chunks.js`) с таблицей слов и кусков, выученной из пар фраз (`lib/rules/align.js`, IBM Model 1 + таблица фраз).
- Модули: `cases.js` (падежи рус → инг), `verbs.js` (времена, будущее -рг-), `sense.js` / `sense-inh.js` (выбор значения слова),
  `inh-verbs.js` (формы ингушских глаголов → русский), `ru-conj.js` / `ru-decl.js` (русские спряжение и склонение),
  имена и новые заимствования остаются как есть.
- Интерфейс: без упоминаний ИИ, нажатие на слово показывает, откуда оно; кнопка «Сообщить об ошибке / Исправить».
- CI: `.github/workflows/tests.yml` гоняет все тесты на каждый пуш и PR.

## Ветки

- `main` — всё слито (PR #22 правки по ревью Grok, #23 перевод без ИИ, #24).
- `claude/sentence-meaning` — от свежего main: тесты по примерам папы («Куда отвезти еду?» → «Мича даар дӀадига»),
  фильтр обрывков вроде «ӀӀ» в таблице слов. **Ещё не на GitHub** (на Mac нет входа в GitHub; ветку передают бандлом
  через `/mnt/project-files/…bundle`, пушит облачный Claude).
- `claude/sentence-templates` — в работе: шаблоны предложений с несколькими «слотами», выученные из ~8000 фраз разговорника.

## Как запустить и проверить

```sh
export PATH=/usr/local/bin:$PATH                 # Node стоит в /usr/local/bin на этом Mac
node server.js                                   # http://localhost:3000
for f in test/*.test.js; do node "$f" || exit 1; done
node scripts/eval-chunks.js                      # рус → инг, честно (5 частей, фраза не видит себя)
node scripts/eval-chunks.js --inh                # инг → рус
node scripts/check-everyday.js --bad             # 466 бытовых предложений, флаги ошибок
node scripts/eval-rules.js                       # правила против разговорника (не должно падать)
node scripts/eval-retrieval.js                   # подсказки; отложенный набор data/eval-holdout.json
```

На Mac тяжёлые запуски — через `nice -n 15 /usr/bin/lockf -k /private/tmp/claude-501/ingush-cpu.lock …`
(просьба владельца: не греть ноутбук; следить за батареей `pmset -g batt`, не ниже 15%).

Последние цифры (база 62 тыс. записей): рус → инг 26.9% слов на месте / 342 фразы целиком;
инг → рус 28.1% / 375. В начале работы было 22.5% / 128 и 18.8% / 152.

## Деплой и данные

- Хостинг: Netlify (функция `api/translate.js`, `netlify.toml`); бесплатный план — каждый прод-деплой стоит кредиты,
  для изменений без сайта — `[skip netlify]` в коммите слияния. Деплой-превью PR бесплатны.
- Исправления с сайта могут храниться в Supabase (`supabase/schema.sql`), если заданы переменные.
- Переменные окружения (только имена, значения — в настройках хостинга / `.env`, никогда в коде):
  `USE_AI`, `EDITOR_CODE`, `GEMINI_API_KEY`, `GEMINI_MODELS`, `OPENROUTER_API_KEY`, `OPENROUTER_MODELS`, `GROQ_API_KEY`,
  `GROQ_MODELS`, `XAI_API_KEY`, `XAI_MODELS`, `DISTILL_MODELS`, `SUPABASE_URL`, `SUPABASE_KEY`, `SUPABASE_SECRET_KEY`,
  `SUPABASE_SERVICE_ROLE_KEY`, `PORT`, `HOST`, `TIME_LIMIT_SECONDS`.
- Grok (другой ИИ) ведёт Netlify, данные (`data/phrases.json`, `scripts/build-phrases.js`), `/review`, раздел «Учить» (PR #19).
  Правило: изменения `api/translate.js` — по одному PR, ветки от свежего main, перед PR все тесты, слияние с `[skip netlify]`.

## Жёсткие правила

- **Не выдумывать ингушский.** Каждое слово — из справочника, словаря проекта, PaydaDosh, текстов или от носителя.
- `verified: true` ставит только человек на `/review`.
- `data/phrases.json` руками не править.
- Формы «пришёл» (вера / хьавенав) и «мы идём» (долха / лелха) ждут носителя — сейчас остаются в [скобках].

## Вопросы к носителю (папе)

- Бывает ли в ингушском «ӀӀ» (двойная палочка)? Примеры из словаря: теӀӀа (вплотную), тоӀӀадаь (туго),
  тӀӀийрг / тӀӀирг (шнур), тӀатеӀӀе болх бе (трудись усердно). Или это ошибка распознавания?
- «Пришёл / пришла»: вера / ера или хьавенав / хьаенай?
- «Мы идём»: долха или лелха?
- Повелительное: приходи, иди, дай, возьми, садись, скажи, смотри, ешь, пей — одному и нескольким.
- Падежи частых слов (дом, село, город, отец, мать, брат, друг, вода, хлеб, машина): кто / чей / кому / с кем / откуда.
- Остальные вопросы — в конце `docs/translation-rules.md`.
