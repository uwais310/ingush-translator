# Contributing

Thank you for wanting to help. This project needs people who know Ingush far more than it needs programmers, so most of this guide is for you, even if you've never used GitHub.

There's a short version in Russian at the end.

## Before you start: two rules

1. **Only real Ingush.** Write what you know as a speaker, or what you found in a source you can name. Please don't send words generated by AI, and don't copy pages from printed dictionaries: they're protected by copyright, and we can't use them.
2. **Say where it comes from.** "My grandmother says it this way", "this is how we say it in our village", or a link to a source are all useful. If people say it differently in different places, tell us that too.

## Report a wrong translation

1. Make a free account at [github.com](https://github.com/signup) if you don't have one.
2. Open the [new issue page](https://github.com/uwais310/ingush-translator/issues/new/choose) and choose **Wrong translation / bug**.
3. Fill in what you typed, what the site answered, and what the correct translation is. A screenshot helps.
4. Press **Create**. You can write in Russian, Ingush or English.

The site shows where each answer came from (a native speaker, the database, the grammar rules, or AI), so please mention that label too. It tells us what to fix.

## Add a missing word or fix a word

1. Open the [new issue page](https://github.com/uwais310/ingush-translator/issues/new/choose) and choose **Add or fix a word**.
2. Write the Russian word and the Ingush word.
3. If you can, add the noun class (в, й, д or б), the plural, an example sentence, and where the word comes from.
4. Press **Create**.

Someone who knows the language checks every suggestion before it goes in.

The **Исправить** (Fix) button on the site saves a correction straight away, but the site owner can limit it to people with an editor code, and the `/review` page always needs one. If you'd like to check translations regularly, ask for a code in an issue.

## For programmers

The site has no build step. You need Node.js 18 or newer, and nothing else to install.

```sh
cp .env.example .env    # optional: GEMINI_API_KEY for the AI step
node server.js          # http://localhost:3000
for f in test/*.test.js; do node "$f"; done
```

Where things live:

| What | Where |
|---|---|
| Server: database, rules, AI and checks | `api/translate.js`, `lib/base.js` |
| Grammar rules (Russian → Ingush, Ingush → Russian) | `lib/rules/grammar.js`, `lib/rules/reverse.js` |
| Word library for the rules (pronouns, verbs, forms) | `lib/rules/lexicon.js` |
| Grammar guide and glossary sent to the AI | `lib/ingush-guide.js` |
| Picking dictionary entries and examples for the AI | `lib/retrieval.js`, `lib/morph.js` |
| Database of word and phrase pairs | `data/phrases.json`, built by `scripts/build-phrases.js` |
| Pages | `index.html`, `review.html`, `rules.html` |

A few habits keep the project trustworthy:

- Every Ingush form in the code needs a source: the project glossary, PaydaDosh, or a native speaker. If a rule isn't sure, it should stay silent and let the next step answer.
- `verified` is only ever set by a person on `/review`. Don't set it in code or data.
- Don't edit `data/phrases.json` by hand. Change the sources or the build script and rebuild. See [SOURCES.md](SOURCES.md).
- New rules come with examples from a source. Run `node test/rules.test.js` and `node scripts/eval-rules.js` to check that agreement with native speakers' translations hasn't gone down.
- API keys go into environment variables only, never into the code.
- Work on a branch and open a pull request against `main`.

## Коротко по-русски

Программировать не нужно. Если вы говорите по-ингушски, лучше всего помогают исправления:

1. Заведите бесплатный аккаунт на [github.com](https://github.com/signup).
2. Откройте [новое обращение](https://github.com/uwais310/ingush-translator/issues/new/choose) и выберите **Wrong translation / bug** (неправильный перевод) или **Add or fix a word** (добавить или исправить слово).
3. Напишите, что вы ввели, что ответил сайт и как правильно. Если знаете, добавьте класс слова (в, й, д, б), множественное число и пример. Можно писать по-русски.

Пишите только то, что знаете сами или можете показать в источнике. Не присылайте слова, придуманные ИИ, и не переписывайте страницы из печатных словарей. Баркал!
